# Animated banner customization

The animated banner is generated by `generate.py` and stored as:

- `assets/banner-dark.svg`
- `assets/banner-light.svg`

## Change the scenes

At the top of `scripts/banner/generate.py`:

```python
SCENE_SEQUENCE = ("portrait", "code", "neural", "cyber")
```

Available scenes:

| Scene | Visual |
|---|---|
| `portrait` | Your dithered portrait, automatically centered |
| `code` | `</>` style developer symbol |
| `neural` | Neural-network / AI topology |
| `cyber` | Security shield + circuit nodes |
| `globe` | Network / global connectivity globe |
| `terminal` | Terminal prompt / command-line motif |
| `java` | Java wordmark-inspired scene |

The first scene must remain `portrait`, because that is the loop's anchor.

Example:

```python
SCENE_SEQUENCE = ("portrait", "neural", "globe", "cyber")
```

## Change the transition feel

Set:

```python
TRANSITION_STYLE = "cinematic"
```

Available styles:

- `cinematic` — slower, polished ease-in/out
- `smooth` — balanced UI-style movement
- `snappy` — faster, more energetic motion
- `linear` — constant-speed movement

## Regenerate

From the repository root:

```bash
python3 scripts/generate.py
```

The workflow in `.github/workflows/update-profile.yml` runs the same generator automatically on GitHub Actions.

## Centering

The portrait particle field is centered using:

```python
VISUAL_CENTER = np.array([244.0, 331.0], dtype=np.float32)
```

This is the center of the banner's visual viewport. You normally should not need to change it.
